🌱 Git

Git sparar historiken för ditt projekt, som sparpunkter i ett spel. Gör AI:n något dumt kan du alltid gå tillbaka.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Installera Git

    Git för Windows innehåller också Git Bash, som Claude Code behöver på Windows.

    PowerShell 
    winget install --id Git.Git -e --source winget
    Terminal 
    brew install git

    Om macOS frågar om du vill installera Command Line Developer Tools, svara ja. Det är också ett sätt att få Git.

    Terminal 
    sudo apt install -y git

    Starta om terminalen och kontrollera:

    Alla system 
    git --version

  2. Berätta vem du är

    Varje sparpunkt (commit) märks med namn och e-post. Använd samma e-post som du har, eller ska ha, på GitHub.

    Alla system 
    git config --global user.name "Ditt Namn"
git config --global user.email "din@epost.se"
git config --global init.defaultBranch main

    Vill du inte visa din e-post offentligt? GitHub ger dig en anonym adress som slutar på @users.noreply.github.com. Du hittar den under Settings → Emails när du har skapat ditt konto.

  3. Ordlista

    OrdBetyder
    Repository (repo)En projektmapp som Git håller koll på.
    CommitEn sparpunkt med en kort beskrivning av vad som ändrats.
    BranchEn parallell version av projektet där du kan testa saker utan att röra huvudversionen.
    Push / PullSkicka dina commits till GitHub, eller hämta andras.
    CloneLadda ner en kopia av ett repo från GitHub till din dator.

  4. Testa

    Det här skapar ett litet repo och gör din första commit. Du behöver inte förstå varje rad än, det går vi igenom på lektionen.

    PowerShell 
    mkdir $HOME\kurs\hej-git
cd $HOME\kurs\hej-git
git init
"Hej från Git!" | Out-File README.md
git add README.md
git commit -m "Min första commit"
git log --oneline
    Terminal 
    mkdir -p ~/kurs/hej-git
cd ~/kurs/hej-git
git init
echo "Hej från Git!" > README.md
git add README.md
git commit -m "Min första commit"
git log --oneline
