⚡ Supabase och Supabase CLI

Supabase ger dig en riktig databas på nätet. Här skapar du konto och ett projekt, installerar kommandoradsverktyget och loggar in, så att agenten kan använda Supabase åt dig.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Vad är Supabase?

    Supabase är en backend som tjänst. Du får färdigt:

    • En databas: Postgres, en av världens vanligaste databaser, med tabeller och SQL som i del 2.
    • Ett REST-API: Supabase gör automatiskt ett API av varje tabell, till exempel /rest/v1/fikor.
    • Regler för vem som får göra vad: Row Level Security bestämmer vem som får läsa, lägga till och ta bort.
    • Inloggning: finns färdigt om du vill bygga vidare.

    Supabase har ett kommandoradsverktyg, Supabase CLI, ungefär som gh för GitHub. När du är inloggad kan agenten använda det åt dig.

  2. Vad det kostar

    PlanPrisDet här ingår
    Free0 dollar2 aktiva projekt, 500 MB databas per projekt, 1 GB filer, 50 000 inloggade användare i månaden och 5 GB trafik.
    Profrån 25 dollar i månaden, drygt 250 kronorStörre gränser, projekt som aldrig pausas och dagliga säkerhetskopior. Fler projekt kostar från 10 dollar i månaden.
    • Gratis räcker för hela kursen. En fikalista använder en bråkdel av gränserna.
    • Projektet pausas: ett gratisprojekt som inte används på en vecka pausas. Datan finns kvar, och du startar det igen med en knapp på supabase.com.
    • Två projekt åt gången: behöver du ett tredje kan du pausa eller ta bort ett gammalt. Pausade projekt räknas inte.

    Priserna ändras. Siffrorna ovan gällde i november 2026. Kolla alltid Supabases prissida innan du väljer en plan som kostar.

  3. Skapa konto

    1. Gå till supabase.com/dashboard/sign-up.
    2. Skapa ett konto. Låt lösenordshanteraren skapa och spara lösenordet.
    3. Bekräfta e-postadressen med länken du får.

    Kontot gör du alltid själv. Agenten ska aldrig få ditt lösenord, och det skrivs aldrig i chatten.

  4. Skapa ett projekt

    1. Klicka på New project. Ge det ett namn, till exempel fikalistan.
    2. Välj en region i Europa, gärna Stockholm om den finns. Då går det snabbare för oss i Sverige.
    3. Supabase ber om ett lösenord till databasen. Låt den skapa ett starkt lösenord och spara det i lösenordshanteraren. Det behöver du snart.
    4. Välj planen Free och vänta någon minut medan projektet startar.

    Projektets adress ser ut så här: https://abcdefghijkl.supabase.co. Bokstäverna i början är projektets id (project ref). Du hittar det också under Project Settings.

  5. Installera Supabase CLI

    På Windows installeras det med Scoop, ett program som installerar andra program. Har du inte Scoop, installera det först i PowerShell:

    PowerShell · Scoop 
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

    Installera sedan Supabase CLI:

    PowerShell 
    scoop bucket add supabase https://github.com/supabase/scoop-bucket.git
scoop install supabase
    Terminal 
    brew install supabase/tap/supabase
    Terminal 
    brew install supabase/tap/supabase

    Har du inte Homebrew finns färdiga paket under Releases på github.com/supabase/cli.

    Stäng terminalen, öppna en ny och kolla att det fungerade:

    Alla system 
    supabase --version
    Vill du inte installera något på hela datorn?

    Supabase CLI kan också installeras i ett projekt med npm install -D supabase. Då skriver du npx supabase i stället för supabase i alla kommandon, och säger det till agenten.

  6. Logga in, själv

    Alla system 
    supabase login

    Webbläsaren öppnas och du godkänner inloggningen. CLI:t sparar en nyckel på din dator. Kolla att det fungerade. Du ska se ditt projekt i listan:

    Alla system 
    supabase projects list

    Nu kan agenten använda supabase åt dig, eftersom den kör kommandon på samma dator och med samma inloggning som du. Precis som med gh.

  7. Nycklarna: vilken får synas?

    Din app behöver projektets adress och en nyckel för att prata med Supabase. Du hittar dem under Project Settings → API Keys.

    NyckelBörjar medVar den får finnas
    Publishable keysb_publishable_Får ligga i frontenden och synas för alla. Det är reglerna i databasen som skyddar datan.
    Secret keysb_secret_Bara på servern, i filen .env. Den går förbi alla regler. Aldrig i frontenden, i Git eller i chatten.

    Den hemliga nyckeln klistrar du in i .env själv, i VS Code. Be agenten skapa filen och se till att den finns i .gitignore, men ge den aldrig själva nyckeln. Samma sak som med API-nyckeln i tillfälle 2.

    Råkade nyckeln hamna i chatten eller på GitHub? Skapa en ny under API Keys och ta bort den gamla. Det tar en minut.
