🔐 Lösenordshanterare

I kursen skapar du konton på flera tjänster: GitHub, Claude eller ChatGPT och fler senare. En lösenordshanterare skapar ett unikt, starkt lösenord för varje konto och kommer ihåg dem åt dig. Du behöver bara kunna ett enda lösenord.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Välj en lösenordshanterare

    Vi rekommenderar en av de här två. Båda krypterar valvet på din egen enhet, så inte ens företaget bakom kan läsa dina lösenord. Båda har appar för dator och mobil samt tillägg till webbläsaren.

    Proton Pass1Password
    PrisGratisplanen räcker för kursen: obegränsat antal lösenord och enheter.Kostar några dollar i månaden. Du kan prova gratis i 14 dagar.
    Passar dig somvill komma igång gratis.vill ha den mest polerade upplevelsen och kan tänka dig att betala.

    Använder du redan en annan lösenordshanterare, till exempel Bitwarden eller den som finns i Apple-enheter? Då kan du fortsätta med den.

  2. Skapa ett konto och välj huvudlösenord

    1. Skapa ett konto på proton.me/pass eller 1password.com.
    2. Välj ett huvudlösenord. Det är det enda lösenord du behöver komma ihåg från och med nu.
    3. Spara återställningsinformationen. 1Password ger dig ett Emergency Kit och Proton en återställningsfras. Skriv ut den eller skriv av den på papper och förvara den hemma.

    Ett bra huvudlösenord är en lösenordsfras med fyra eller fem slumpmässiga ord, till exempel kanel-cykel-moln-tallrik-hopp. Den är lång och svår att gissa men lätt att komma ihåg. Använd den inte någon annanstans.

    Glöm inte huvudlösenordet. Ingen kan återställa det åt dig utan återställningsinformationen, inte ens företaget.

  3. Installera appen på datorn

    Det enklaste är att ladda ner appen från länken i tabellen ovan och installera den som vilket program som helst. Logga sedan in med ditt konto.

    Vill du hellre installera med terminalen?
    PowerShell · Proton Pass 
    winget install --id Proton.ProtonPass -e
    PowerShell · 1Password 
    winget install --id AgileBits.1Password -e

    Kräver Homebrew, som du installerar i nästa guide.

    Terminal · Proton Pass 
    brew install --cask proton-pass
    Terminal · 1Password 
    brew install --cask 1password

    Kommandona gäller Ubuntu och Debian. Fedora har .rpm-paket på samma nedladdningssidor.

    Terminal · Proton Pass 
    wget https://proton.me/download/PassDesktop/linux/x64/ProtonPass.deb
sudo apt install ./ProtonPass.deb
    Terminal · 1Password 
    wget https://downloads.1password.com/linux/debian/amd64/stable/1password-latest.deb
sudo apt install ./1password-latest.deb

  4. Lägg till tillägget i webbläsaren och appen i mobilen

    Webbläsartillägget är det du kommer använda mest. Det fyller i användarnamn och lösenord när du loggar in och föreslår ett starkt lösenord när du skapar ett nytt konto. Det finns för Chrome, Edge, Firefox, Safari och Brave på samma nedladdningssidor.

    Installera gärna mobilappen också (App Store eller Google Play), så har du dina lösenord med dig överallt.

  5. Använd den för kursens konton

    När du skapar konton i nästa guider (GitHub, Claude eller ChatGPT) gör du så här:

    1. Klicka i lösenordsfältet och välj att låta lösenordshanteraren skapa ett lösenord.
    2. Spara inloggningen när tillägget frågar.
    3. Nästa gång du loggar in fyller tillägget i allt åt dig.

    Tvåstegsverifiering: GitHub kräver en engångskod utöver lösenordet. 1Password och Proton Pass Plus kan spara och fylla i koderna. Med gratisversionen av Proton Pass använder du i stället en autentiseringsapp i mobilen.
