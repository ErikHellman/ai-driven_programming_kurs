⌨️ Terminalen

Terminalen är ett fönster där du skriver kommandon till datorn i stället för att klicka. Vi kör AI-agenterna i appar, men terminalen behövs för att installera verktyg och för Git och GitHub. Agenterna använder den också bakom kulisserna.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Öppna terminalen

    Tryck på Win, skriv Terminal och tryck Enter. Windows Terminal öppnas med PowerShell, och det är den vi använder i kursen.

    Hittar du inte Windows Terminal (vanligt på äldre Windows 10)? Öppna PowerShell från startmenyn och installera den:

    PowerShell 
    winget install --id Microsoft.WindowsTerminal -e

    Tryck ⌘ + Mellanslag, skriv Terminal och tryck Enter.

    Tips: Högerklicka på Terminal i Dock och välj Behåll i Dock så hittar du den snabbt.

    På de flesta distributioner öppnar Ctrl + Alt + T en terminal. Annars letar du efter Terminal bland programmen.

  2. Prova några kommandon

    Skriv ett kommando och tryck Enter. Inget kan gå sönder av de här.

    PowerShell 
    # Var är jag?
pwd
# Vad finns i mappen?
ls
# Skapa en mapp för kursen och gå in i den
mkdir $HOME\kurs
cd $HOME\kurs
    Terminal 
    # Var är jag?
pwd
# Vad finns i mappen?
ls
# Skapa en mapp för kursen och gå in i den
mkdir -p ~/kurs
cd ~/kurs

    Bra att veta: ↑ tar fram förra kommandot, Tab fyller i fil- och mappnamn, och Ctrl + C avbryter ett kommando som hänger sig.

  3. Installera en pakethanterare

    En pakethanterare är en ”app-butik för terminalen”. Med den installerar du program med ett enda kommando.

    Windows 10 och 11 har redan winget inbyggt. Kontrollera att det fungerar:

    PowerShell 
    winget --version

    Får du ett fel? Öppna Microsoft Store, sök efter App Installer och uppdatera den. Starta sedan om terminalen.

    På macOS använder vi Homebrew. Klistra in kommandot och följ instruktionerna. Du får skriva in ditt lösenord (det syns inte när du skriver, det är normalt).

    Terminal 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Viktigt: När installationen är klar skriver den ut Next steps med två eller tre kommandon som börjar med echo och eval. Kopiera och kör dem, annars hittar terminalen inte brew.

    Kontrollera sedan:

    Terminal 
    brew --version

    Din distribution har redan en pakethanterare. I guiderna visar vi kommandon för Ubuntu och Debian (apt). Använder du Fedora byter du apt mot dnf.

    Terminal 
    sudo apt update
sudo apt install -y curl wget

  4. Starta om terminalen efter installationer

    När du har installerat något nytt behöver terminalen ibland startas om för att hitta programmet. Får du felet command not found eller känns inte igen, stäng terminalfönstret och öppna ett nytt.
