🟩 Node.js

Node.js kör JavaScript utanför webbläsaren. Många verktyg och webbprojekt som AI:n bygger åt dig behöver det, och med npm kan du installera Codex.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Installera Node.js (LTS)

    LTS betyder Long Term Support, den stabila versionen.

    PowerShell 
    winget install --id OpenJS.NodeJS.LTS -e

    Felet ”running scripts is disabled”? PowerShell blockerar ibland npm. Kör det här en gång och svara Y:

    PowerShell 
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    Terminal 
    brew install node

    Versionen i apt är ofta för gammal. Vi använder nvm, som installerar den senaste LTS-versionen i din hemmapp.

    Terminal 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
# Starta om terminalen, sedan:
nvm install --lts

  2. Kontrollera

    Starta om terminalen och kör:

    Alla system 
    node --version
npm --version

    Du ska se två versionsnummer, till exempel v24.x.x och 11.x.x.
