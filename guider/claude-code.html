✳️ Claude Code

Claude Code är Anthropics AI-agent. Den läser dina filer, skriver kod och kör kommandon åt dig, direkt i terminalen eller i VS Code.

Vi gissade ditt operativsystem. Byt om det blev fel.

Du behöver ett konto. Claude Code ingår i Claudes betalabonnemang (Pro eller Max). Skapa konto på claude.ai innan du börjar. Pro räcker för kursen.

  1. Installera

    Kör i PowerShell. Se till att du har installerat Git först.

    PowerShell 
    irm https://claude.ai/install.ps1 | iex

    Eller med winget:

    PowerShell 
    winget install Anthropic.ClaudeCode
    Terminal 
    curl -fsSL https://claude.ai/install.sh | bash

    Eller med Homebrew:

    Terminal 
    brew install --cask claude-code

    Starta om terminalen och kontrollera:

    Alla system 
    claude --version

  2. Starta och logga in

    Gå till en projektmapp och starta Claude Code:

    PowerShell 
    mkdir $HOME\kurs\forsta-projektet
cd $HOME\kurs\forsta-projektet
claude
    Terminal 
    mkdir -p ~/kurs/forsta-projektet
cd ~/kurs/forsta-projektet
claude

    Första gången får du välja färgtema och logga in. Välj Claude account with subscription, godkänn i webbläsaren och svara ja på frågan om du litar på mappen.

  3. Ge den ditt första uppdrag

    Skriv på svenska, precis som till en kollega:

    Skriv i Claude Code 
    Skapa en enkel webbsida index.html som hälsar mig välkommen till kursen. Använd varma färger.

    Claude frågar om lov innan den skapar filer eller kör kommandon. Läs vad den vill göra och godkänn.

  4. Bra att kunna

    KommandoGör
    /helpVisar hjälp och alla kommandon.
    /initSkapar filen CLAUDE.md med instruktioner om projektet.
    /clearBörjar om med en tom konversation.
    EscAvbryter det Claude håller på med.
    Shift + TabVäxlar läge, till exempel planeringsläge eller automatiskt godkännande.
    /exitAvslutar.

    Hellre en app? Claude Code finns också i Claudes skrivbordsapp och på webben. Ladda ner appen från claude.ai/download. I kursen utgår vi från terminalen.
