✳️ Claude Code

Claude Code är Anthropics AI-agent. I kursen använder vi den i Claude-appen på datorn, under fliken Code. Där läser den dina filer, skriver kod och kör kommandon åt dig, och du ser varje ändring innan den sparas.

Vi gissade ditt operativsystem. Byt om det blev fel.

Du behöver ett betalabonnemang. Claude Code ingår i Claude Pro, Max, Team och Enterprise. Skapa konto på claude.ai innan du börjar. Pro räcker för kursen.

  1. Installera Claude-appen

    Ladda ner installationsprogrammet och kör det:

    • Claude för Windows (x64), det vanliga valet
    • Claude för Windows (ARM64), för datorer med Snapdragon-processor

    Installera Git först. Claude Code använder Git för att hålla koll på ändringar och för att kunna köra flera uppgifter parallellt.

    Ladda ner Claude för macOS (fungerar på både Intel och Apple Silicon). Öppna filen och dra Claude till mappen Program.

    Linux-appen är i beta och finns för Ubuntu 22.04+ och Debian 12+. Kör stegen i ordning:

    Terminal 
    # 1. Verktyg som behövs för att lägga till Anthropics paketkälla
sudo apt install -y curl gnupg
# 2. Anthropics signeringsnyckel
sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc https://downloads.claude.ai/claude-desktop/key.asc
# 3. Lägg till paketkällan
echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main" | sudo tee /etc/apt/sources.list.d/claude-desktop.list
# 4. Installera
sudo apt update && sudo apt install -y claude-desktop

    Använder du Fedora eller Arch? Då finns ingen app ännu. Använd terminalversionen längst ner på sidan.

  2. Logga in och öppna fliken Code

    Starta Claude och logga in med ditt Claude-konto. Klicka sedan på fliken Code högst upp i mitten. Appen har tre flikar:

    FlikAnvänds till
    ChatVanlig chatt, utan tillgång till dina filer.
    CoworkLängre uppgifter som Claude gör i bakgrunden.
    CodeClaude Code. Det är den vi använder i kursen.

    Ber appen dig uppgradera när du klickar på Code saknar ditt konto ett betalabonnemang.

  3. Välj en projektmapp

    Skapa först en tom mapp för ditt första projekt, till exempel kurs/forsta-projektet i din hemmapp. I Code-fliken:

    1. Välj Local så att Claude jobbar med filerna på din dator.
    2. Klicka på Select folder och välj mappen.
    3. Välj behörighetsläge med väljaren bredvid skicka-knappen. Börja med Manual, då frågar Claude innan den ändrar filer eller kör kommandon.
    LägeVad Claude får göra
    ManualFrågar innan varje filändring och kommando. Bäst när du är ny.
    Accept editsÄndrar filer direkt, men frågar innan andra kommandon.
    PlanLäser och föreslår en plan, men ändrar ingenting.
    AutoJobbar på utan att fråga, och en automatisk kontroll stoppar riskabla saker.

  4. Ge Claude ditt första uppdrag

    Skriv på svenska, precis som till en kollega, och tryck Enter:

    Skriv i Claude 
    Skapa en enkel webbsida index.html som hälsar mig välkommen till kursen. Använd varma färger.

    I läget Manual ser du exakt vad som kommer att ändras och trycker Accept eller Reject. När filer har ändrats visas en markering som +12 -1. Klicka på den för att se alla ändringar.

  5. Bra att kunna

    • Avbryt eller styr om: klicka på stoppknappen, eller skriv en rättelse och tryck Enter medan Claude jobbar.
    • Peka på en fil: skriv @ följt av filnamnet.
    • Bifoga bilder: dra in en skärmdump eller skiss direkt i textrutan.
    • Inbyggd terminal: Ctrl + ` öppnar en terminal i projektmappen.
    • Projektinstruktioner: be Claude skapa en CLAUDE.md med instruktioner om projektet.
Vill du hellre köra Claude Code i terminalen?

Det är samma Claude Code, men utan grafiskt gränssnitt. Den behövs bara om du inte kan använda appen, till exempel på Fedora eller Arch.

PowerShell 
irm https://claude.ai/install.ps1 | iex
Terminal 
curl -fsSL https://claude.ai/install.sh | bash

Starta sedan med claude i en projektmapp.
