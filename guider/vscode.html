📝 VS Code

Visual Studio Code är en gratis kodeditor. Här ser du filerna som AI:n skapar, granskar ändringarna och kör agenten i en panel bredvid koden.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Installera VS Code

    PowerShell 
    winget install --id Microsoft.VisualStudioCode -e
    Terminal 
    brew install --cask visual-studio-code
    Terminal 
    sudo snap install code --classic

    Har du inte snap? Ladda ner .deb-filen från code.visualstudio.com/download och installera den.

    Starta om terminalen och kontrollera att kommandot code fungerar:

    Alla system 
    code --version

    Hittas inte code? Öppna VS Code, tryck ⌘ + Shift + P, skriv shell command och välj Install 'code' command in PATH.

  2. Installera rekommenderade tillägg

    Kopiera hela blocket och kör det i terminalen. Du kan också söka upp tilläggen under Extensions i VS Code (Ctrl/⌘ + Shift + X).

    Alla system 
    code --install-extension anthropic.claude-code
code --install-extension openai.chatgpt
code --install-extension github.vscode-pull-request-github
code --install-extension ritwickdey.liveserver
    TilläggVarför
    Claude CodeKör Claude Code i en panel i VS Code och visar ändringar sida vid sida.
    Codex (openai.chatgpt)Samma sak för Codex.
    GitHub Pull RequestsSe och granska pull requests från GitHub direkt i editorn.
    Live ServerÖppnar webbsidor du bygger i webbläsaren och laddar om dem automatiskt.

    Du behöver bara tillägget för den agent du har valt, men det skadar inte att ha båda.

  3. Öppna en mapp

    I VS Code arbetar man alltid i en mapp, inte i en enskild fil. Gå till kursmappen och öppna den:

    PowerShell 
    cd $HOME\kurs
code .
    Terminal 
    cd ~/kurs
code .

    Punkten betyder ”den mapp jag står i”. Svara Yes, I trust the authors om VS Code frågar.

    Tips: VS Code har en inbyggd terminal. Öppna den via menyn Terminal → New Terminal.
