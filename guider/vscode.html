📝 VS Code

Visual Studio Code är en gratis kodeditor. AI-agenten jobbar i Claude- eller ChatGPT-appen, och VS Code använder vi bara för att titta på filerna och göra mindre ändringar själv. Du behöver inte installera några tillägg.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Installera VS Code

    PowerShell 
    winget install --id Microsoft.VisualStudioCode -e
    Terminal 
    brew install --cask visual-studio-code
    Terminal 
    sudo snap install code --classic

    Har du inte snap? Ladda ner .deb-filen från code.visualstudio.com/download och installera den.

    Starta om terminalen och kontrollera att kommandot code fungerar:

    Alla system 
    code --version

    Hittas inte code? Öppna VS Code, tryck ⌘ + Shift + P, skriv shell command och välj Install 'code' command in PATH.

  2. Öppna en mapp

    I VS Code arbetar man alltid i en mapp, inte i en enskild fil. Gå till kursmappen och öppna den:

    PowerShell 
    cd $HOME\kurs
code .
    Terminal 
    cd ~/kurs
code .

    Punkten betyder ”den mapp jag står i”. Svara Yes, I trust the authors om VS Code frågar.

    Du kan också öppna mappen via menyn File → Open Folder.

  3. Gör en liten ändring

    Ibland går det snabbare att ändra en text eller en färg själv än att be agenten. Så här gör du:

    1. Klicka på filen i listan till vänster (Explorer), till exempel index.html.
    2. Ändra det du vill, till exempel en rubrik.
    3. Spara med Ctrl + S (Windows och Linux) eller ⌘ + S (macOS). En prick på fliken betyder att filen inte är sparad.
    4. Ladda om sidan i webbläsaren för att se ändringen.

    Se vad som har ändrats: Ikonen Source Control i vänsterkanten visar alla filer som ändrats sedan den senaste sparpunkten i Git, både dina och agentens ändringar. Klicka på en fil för att se före och efter sida vid sida. Det är inbyggt, inga tillägg behövs.
