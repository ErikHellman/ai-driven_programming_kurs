🐙 GitHub och gh

GitHub är där dina Git-projekt bor på nätet. Med verktyget gh pratar du med GitHub direkt från terminalen, och det kan AI-agenterna också.

Vi gissade ditt operativsystem. Byt om det blev fel.

  1. Skapa ett konto på GitHub

    1. Gå till github.com/signup.
    2. Fyll i e-post, lösenord och ett användarnamn. Låt lösenordshanteraren skapa och spara lösenordet. Användarnamnet syns publikt, så välj något du är bekväm med.
    3. Bekräfta e-postadressen med koden du får.
    4. Välj gratisplanen (Free). Den räcker gott för hela kursen.

    Slå på tvåstegsverifiering. GitHub kräver det förr eller senare. Gå till Settings → Password and authentication och följ guiden, till exempel med en autentiseringsapp i mobilen.

  2. Installera GitHub CLI (gh)

    PowerShell 
    winget install --id GitHub.cli -e
    Terminal 
    brew install gh

    Det här är GitHubs officiella instruktion för Ubuntu och Debian. Kopiera hela blocket på en gång.

    Terminal 
    (type -p wget >/dev/null || (sudo apt update && sudo apt install wget -y)) \
  && sudo mkdir -p -m 755 /etc/apt/keyrings \
  && out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
  && cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
  && sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
  && sudo mkdir -p -m 755 /etc/apt/sources.list.d \
  && echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
  && sudo apt update \
  && sudo apt install gh -y

    Andra distributioner: se github.com/cli/cli.

    Starta om terminalen och kontrollera:

    Alla system 
    gh --version

  3. Logga in

    Alla system 
    gh auth login

    Svara så här på frågorna (flytta med piltangenterna, välj med Enter):

    FrågaSvar
    Where do you use GitHub?GitHub.com
    Preferred protocol for Git operations?HTTPS
    Authenticate Git with your GitHub credentials?Yes
    How would you like to authenticate?Login with a web browser

    Terminalen visar en kod på åtta tecken. Tryck Enter, klistra in koden i webbläsaren som öppnas och godkänn.

    Kontrollera att det fungerade:

    Alla system 
    gh auth status

  4. Lägg upp ditt första repo

    Har du gjort testet i Git-guiden? Då kan du skicka upp det till GitHub med ett kommando:

    PowerShell 
    cd $HOME\kurs\hej-git
gh repo create hej-git --private --source . --push
    Terminal 
    cd ~/kurs/hej-git
gh repo create hej-git --private --source . --push

    Öppna repot i webbläsaren:

    Alla system 
    gh repo view --web
