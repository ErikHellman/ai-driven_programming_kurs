🌀 Codex

Codex är OpenAIs AI-agent för programmering. Den fungerar på samma sätt som Claude Code: läser filer, skriver kod och kör kommandon åt dig.

Vi gissade ditt operativsystem. Byt om det blev fel.

Du behöver ett konto. Codex ingår i ChatGPT:s betalabonnemang (Plus, Pro, Business m.fl.). Logga in på chatgpt.com och kontrollera ditt abonnemang innan du börjar.

  1. Installera

    PowerShell 
    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

    Eller med npm (kräver Node.js):

    PowerShell 
    npm install -g @openai/codex

    Krånglar det på Windows? OpenAI rekommenderar fortfarande WSL (Linux i Windows) för bästa stöd. Fråga mig på lektionen så hjälper jag dig.

    Terminal 
    curl -fsSL https://chatgpt.com/codex/install.sh | sh

    Eller med Homebrew eller npm:

    Terminal 
    brew install --cask codex
# eller
npm install -g @openai/codex

    Starta om terminalen och kontrollera:

    Alla system 
    codex --version

  2. Starta och logga in

    PowerShell 
    mkdir $HOME\kurs\forsta-projektet
cd $HOME\kurs\forsta-projektet
codex
    Terminal 
    mkdir -p ~/kurs/forsta-projektet
cd ~/kurs/forsta-projektet
codex

    Välj Sign in with ChatGPT och godkänn i webbläsaren.

  3. Ge den ditt första uppdrag

    Skriv i Codex 
    Skapa en enkel webbsida index.html som hälsar mig välkommen till kursen. Använd varma färger.

    Codex visar vad den tänker göra och ber om lov innan den kör kommandon.

  4. Bra att kunna

    KommandoGör
    /initSkapar filen AGENTS.md med instruktioner om projektet.
    /approvalsVäljer hur mycket Codex får göra utan att fråga.
    /modelByter modell och hur mycket den ska tänka.
    /newBörjar om med en tom konversation.
    EscAvbryter det Codex håller på med.
    /quitAvslutar.

    Hellre en app? Codex finns också som app och i ChatGPT på webben. Läs mer på developers.openai.com/codex. I kursen utgår vi från terminalen.
