🌀 Codex

Codex är OpenAIs AI-agent för programmering. I kursen använder vi den i ChatGPT-appen på datorn. Där läser den dina filer, skriver kod och kör kommandon åt dig.

Vi gissade ditt operativsystem. Byt om det blev fel.

Du behöver ett ChatGPT-konto. Logga in på chatgpt.com och kontrollera att ditt abonnemang (till exempel Plus) ger tillgång till Codex innan du börjar.

  1. Installera ChatGPT-appen

    Installera från Microsoft Store, eller med winget:

    PowerShell 
    winget install --id 9PLM9XGG6VKS -s msstore

    Installera Git också. Utan Git fungerar inte alla funktioner i appen.

    Ladda ner appen för macOS, öppna filen och dra appen till mappen Program.

    Appen kräver Apple Silicon (M1 eller senare). Har du en äldre Mac med Intel-processor använder du terminalversionen längst ner på sidan.

    Linux-appen är i förhandsversion. Ubuntu 24.04+ och Debian 13 (x64):

    Terminal 
    cd ~/Downloads
curl -fLO https://persistent.oaistatic.com/codex-app-prod/linux/deb/latest/chatgpt_amd64.deb
sudo apt install ./chatgpt_amd64.deb

    Fedora 43+ (x64):

    Terminal 
    cd ~/Downloads
curl -fLO https://persistent.oaistatic.com/codex-app-prod/linux/rpm/latest/chatgpt.x86_64.rpm
sudo dnf install ./chatgpt.x86_64.rpm

    ARM-dator, Arch eller annan distribution? Se OpenAIs Linux-instruktioner.

  2. Logga in och välj Codex

    Starta appen och logga in med ditt ChatGPT-konto. Välj sedan Codex i rullgardinsmenyn högst upp. Det är där du jobbar med kod i en projektmapp.

  3. Öppna en projektmapp

    Skapa först en tom mapp för ditt första projekt, till exempel kurs/forsta-projektet i din hemmapp. Välj sedan Add new project (eller tryck Ctrl/⌘ + O) och välj mappen.

    Under textrutan väljer du hur mycket Codex får göra på egen hand. Börja med att låta den fråga om lov (Ask for approval). Undvik Full access, för då är Codex inte begränsad till projektmappen.

  4. Ge Codex ditt första uppdrag

    Skriv på svenska, precis som till en kollega, och tryck Enter:

    Skriv i Codex 
    Skapa en enkel webbsida index.html som hälsar mig välkommen till kursen. Använd varma färger.

    Codex visar vad den gör och ber om lov innan den kör kommandon. Läs vad den vill göra innan du godkänner.

  5. Bra att kunna

    • Avbryt: klicka på stoppknappen om Codex är på väg åt fel håll.
    • Bifoga bilder: dra in en skärmdump eller skiss direkt i textrutan.
    • Projektinstruktioner: be Codex skapa en AGENTS.md med instruktioner om projektet.
Vill du hellre köra Codex i terminalen?

Det är samma Codex, men utan grafiskt gränssnitt. Den behövs bara om appen inte fungerar på din dator, till exempel på en Intel-Mac.

PowerShell 
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
Terminal 
curl -fsSL https://chatgpt.com/codex/install.sh | sh

Starta sedan med codex i en projektmapp och välj Sign in with ChatGPT.
