Installationsguider

Följ guiderna i ordning. Varje guide har kommandon för både Windows och macOS/Linux, och du kan kopiera dem med ett klick.

⌨️

1. Terminalen

Öppna terminalen och installera en pakethanterare.

Windows · macOS · Linux 🌱

2. Git

Versionshantering, ditt skyddsnät när AI ändrar i koden.

Windows · macOS · Linux 🐙

3. GitHub och gh

Skapa konto, installera GitHub CLI och logga in.

Windows · macOS · Linux 🟩

4. Node.js

Kör JavaScript-verktyg och webbprojekt på din dator.

Windows · macOS · Linux 📝

5. VS Code

Kodeditor för att titta närmare på filerna som AI:n skapar.

Windows · macOS · Linux ✳️

6a. Claude Code

Anthropics AI-agent, i Claude-appen på datorn.

Windows · macOS · Linux 🌀

6b. Codex

OpenAIs AI-agent, i ChatGPT-appen på datorn.

Windows · macOS · Linux

Claude Code eller Codex? Du behöver bara en av dem. Har du redan ett Claude-abonnemang väljer du Claude Code, har du ChatGPT väljer du Codex. Båda fungerar för allt vi gör i kursen.

Checklista inför första övningen

När du är klar ska de här kommandona fungera i terminalen. Varje kommando ska skriva ut ett versionsnummer eller ett ”Logged in”.

Alla system 
git --version
gh auth status
node --version
code --version
  • Jag har ett GitHub-konto och är inloggad med gh
  • Jag har berättat för Git vem jag är (namn och e-post)
  • Jag har installerat Claude-appen eller ChatGPT-appen, loggat in och valt en projektmapp
  • Jag har öppnat en mapp i VS Code
