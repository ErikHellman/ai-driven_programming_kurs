🕵️ Detektiv i Dev Tools

Fikalistan är en liten webbapp med några fel inbyggda med flit. Använd webbläsarens Dev Tools för att hitta dem.

Så börjar du: öppna Fikalistan i en ny flik i Chrome eller Edge. Tryck sedan F12, eller ⌥ + ⌘ + I på Mac, för att öppna Dev Tools.

  1. 🧱 Elements: byt rubriken

    Klicka på pilikonen längst upp till vänster i Dev Tools och sedan på rubriken Fikalistan. Dubbelklicka på texten i Elements och skriv ditt eget namn. Prova också att ändra färgen under Styles.

    Ladda om sidan. Vad hände med din ändring?

    Svar

    Ändringen försvinner. Dev Tools ändrar bara sidan i din webbläsare just nu, inte filerna på servern. Bra för att prova idéer innan du ber agenten om ändringen.

  2. 📡 Network: vilken fil saknas?

    Öppna fliken Network och ladda om sidan. Nu ser du alla filer som webbläsaren hämtar. En av dem är röd.

    • Vilken fil är det, och vilken statuskod har den?
    • Vilken fil hämtar förslagen under rubriken Förslag?
    Svar

    kanelbulle.png ger 404: bilden finns inte på servern. Därför syns en trasig bild överst på sidan. Förslagen kommer från fika.json, som JavaScript hämtar med fetch.

  3. 💬 Console: varför fungerar inte knappen?

    Öppna fliken Console och klicka på knappen 🧮 Räkna fikat i appen. Det händer ingenting på sidan, men något dyker upp i Console.

    Kopiera felmeddelandet. Hur skulle du beskriva felet för agenten?

    Svar

    Felet är ReferenceError: antalBullar is not defined. Koden använder ett namn som inte finns. Så här kan du skriva till agenten:

    Prompt 
    När jag klickar på knappen ”Räkna fikat” händer ingenting. I Console står det: Uncaught ReferenceError: antalBullar is not defined (app.js:78). Ta reda på varför och rätta det.

  4. 🗄️ Application: gammal data

    Lägg till några saker i listan. Öppna fliken Application, välj Local storage i vänsterkolumnen och klicka på adressen under den. Där ser du nyckeln fikalistan och allt du har lagt till.

    Klicka nu på 🕰️ Ladda gammal data i appen. Den låtsas att en äldre version av appen sparade listan på ett annat sätt. Vad händer med listan? Prova att lägga till något nytt och titta i Console.

    Laga appen: ta bort nyckeln i Application och ladda om sidan.

    Svar

    Listan fylls med rader där det står undefined, och nya saker går inte att lägga till. Appen försöker läsa datan i det nya formatet, men den är sparad i det gamla. Markera raden fikalistan och tryck Delete, eller använd Storage → Clear site data. Då fungerar appen igen, men listan är tom.

    Kom ihåg: när du rensar sparad data försvinner den för gott. Be agenten lägga till en exportknapp om datan är viktig för dig.

  5. 📱 Mobilvy och en annan enhet

    Klicka på mobilikonen uppe till vänster i Dev Tools och välj en telefon i listan högst upp. Hur ändras layouten?

    Öppna sedan Fikalistan i mobilen, eller i ett privat fönster. Finns sakerna du lade till på datorn där?

    Svar

    På smala skärmar hamnar fältet och knappen under varandra, det är CSS som anpassar sig. Listan i mobilen är tom: localStorage finns bara i webbläsaren där du sparade den. För att dela data mellan enheter behövs en server.
