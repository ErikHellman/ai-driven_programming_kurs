Lösenordshanterare

Ett valv för alla dina konton

Lösenordshanterare

Många nya konton idag

  • 🐙GitHub, Claude eller ChatGPT, och fler under kursen
  • 🔁Samma lösenord överallt? Läcker det på ett ställe öppnar det alla dörrar.
  • 🧠Ett unikt, starkt lösenord per konto går inte att komma ihåg själv
🔐

Lösningen

En lösenordshanterare skapar och kommer ihåg alla lösenord. Du behöver bara kunna ett.

  • Fråga hur många som använder samma lösenord på flera ställen. Ingen skam, det är vanligt.
  • Poängen: vi skapar flera konton idag, så det är rätt läge att börja.
Lösenordshanterare

Så fungerar det

🔑 HuvudlösenordDet enda du behöver kunna
→
🔐 Krypterat valvAlla lösenord, låsta på din enhet
→
💻📱 Alla enheterDator, mobil och webbläsare
→
✨ Fyller i åt digOch skapar nya starka lösenord

Valvet krypteras innan det lämnar din dator. Inte ens företaget bakom kan läsa dina lösenord.

  • Huvudlösenordet låser upp valvet lokalt. Molnet ser bara krypterad data.
  • Därför kan ingen återställa huvudlösenordet åt dig, spara återställningsinformationen.

Terminalen

Datorns kommandorad

Terminalen

Prata med datorn i text

  • I stället för att klicka skriver du ett kommando och trycker Enter
  • Det är snabbt, exakt och går att upprepa
  • AI-agenter jobbar på samma sätt: de skriver kommandon åt dig
$ pwd
/Users/anna
$ mkdir kurs
$ cd kurs
$ ls
# tomt, än så länge!
  • Windows: Win-tangenten, skriv Terminal. Mac: Cmd + mellanslag, skriv Terminal.
  • Låt alla skriva pwd, mkdir kurs, cd kurs tillsammans.
  • Tips: pil upp tar fram förra kommandot, Tab fyller i namn, Ctrl+C avbryter.
Terminalen

Pakethanterare: en app-butik i terminalen

🪟

Windows: winget

Finns redan inbyggt i Windows 10 och 11.

> winget --version
🍎

macOS: Homebrew

Installeras en gång. Linux har redan apt.

$ brew --version

👉 Följ guide 1 på kurssidan. Mac: glöm inte att köra kommandona under Next steps efter installationen!

  • Homebrew tar några minuter. Starta installationen och fortsätt prata under tiden.
  • Vanligaste felet: man missar Next steps, och då hittas inte brew.

Git

💾 Commit 1Första sidan
→
💾 Commit 2La till meny

💥 Commit 3AI:n förstörde något

När en AI ändrar många filer på en gång är Git det som gör att du vågar låta den jobba.

  • Git är det viktigaste verktyget för den som jobbar med AI-agenter. Vi kan alltid backa.
  • Agenterna kan själva göra commits åt oss, men vi måste förstå idén.

GitHub

Program på din dator som sparar historiken för ett projekt.

GitHub

En webbtjänst där repon lagras, delas och samarbetas kring. Och där du kan publicera webbsidor gratis.

  • Backup av allt du bygger
  • Dela med andra, eller håll det privat

GitHub · gör så här

Skapa ett konto

  • 1️⃣Gå till github.com/signup
  • 2️⃣E-post, lösenord från lösenordshanteraren och ett användarnamn (syns publikt)
  • 3️⃣Bekräfta e-posten med koden du får
  • 4️⃣Välj Free, det räcker
  • 5️⃣Slå på tvåstegsverifiering
💡

Tips

Välj ett användarnamn du kan tänka dig att visa för en framtida arbetsgivare.

  • Ge alla några minuter. De som redan har konto kan installera gh under tiden.

Om något krånglar

Vanliga problem

”command not found”

Stäng terminalen och öppna en ny. Programmet installerades men terminalen vet inte om det än.

”running scripts is disabled”

Windows: kör Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

brew hittas inte

Kör kommandona under Next steps från Homebrew-installationen.

Lösenordet syns inte

Det är normalt i terminalen. Skriv och tryck Enter.
